## 🚀 What I Work On

I'm a Software Engineer at **[AnywhereWorks](https://anywhere.co)**, where I build and maintain a large-scale micro-frontend platform used by thousands of businesses worldwide. My day-to-day spans React/TypeScript feature work, Node.js and Java backend services, Dockerised deploys on GCP, and the agentic workflows I build to automate the rest.

- 🔧 Micro-frontend architecture with **Webpack 5 Module Federation**
- ⚛️ Product features in **React + TypeScript**, state in **Zustand** and Redux
- ⚡ **Vite** builds and **Vitest** across the monorepo — unit plus real-browser component tests
- 📖 A shared **Storybook** that aggregates stories from every microfrontend package
- 🎨 Integrating a custom **EDS (Earth Design System)** component library
- 🌐 Multi-brand login & auth flows across 10+ white-label products
- 📦 A **pnpm** monorepo with **Turborepo** for shared packages
- 🟢 Backend services in **Node.js** — **Fastify** and **Express** APIs, plus a clustered real-time messaging service
- 🧠 **Redis** for session storage and caching — ioredis on Node, Lettuce on Spring
- ☕ **Java Spring MVC** REST APIs across the stack
- 🐳 **Docker** images via multi-stage builds that compile a Node frontend and a Gradle/JDK backend into one runtime image
- ☁️ Deploying on **GCP** — Cloud Run, Artifact Registry, Cloud Build, GCS-hosted MFE bundles, Datastore, Secret Manager, and CDN invalidation, authenticated keylessly from GitHub Actions
- 🤖 Agentic engineering with **Claude**, **Antigravity**, and other LLMs in the daily loop
- 🛠️ Tailor-made **AI skills** for architecture design, feature builds, and bug fixes — collapsing multi-hour workflows into single-command runs
- 🔌 Wiring **MCP** integrations across issue tracking, error monitoring, design and browser automation, including custom MCP servers for internal data
